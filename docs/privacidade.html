Política de Privacidade

Última atualização: Novembro de 2026

Esta Política de Privacidade descreve como os aplicativos funny-spitz-family (associado ao canal Funny Spitz Family — @FunnySpitzFamily) e EmpreendaComigoH2b (associado ao canal Empreenda Comigo — @emprenda_comigo-h2b) lidam com informações e permissões de API do Google.

1. Finalidade e Escopo de Uso

Os aplicativos funny-spitz-family e EmpreendaComigoH2b são ferramentas privadas de automação de produção e publicação audiovisual utilizadas exclusivamente pelo proprietário e administrador dos respectivos canais oficiais no YouTube.

2. Dados Acessados via Google / YouTube API

Os aplicativos solicitam apenas as permissões necessárias da YouTube Data API v3 (https://www.googleapis.com/auth/youtube.upload e https://www.googleapis.com/auth/youtube) para publicar vídeos, definir miniaturas (thumbnails), títulos, descrições e tags nos canais autenticados pelo próprio administrador. Nenhum dado pessoal de terceiros ou de visitantes é coletado, armazenado em servidores externos, vendido ou compartilhado.

3. Armazenamento e Segurança

Os tokens de autenticação OAuth 2.0 são armazenados de forma segura e criptografada apenas no ambiente privado do proprietário dos canais e podem ser revogados a qualquer momento nas configurações de segurança da Conta Google (myaccount.google.com/permissions).

4. Conformidade com a Política do Google

O uso de informações recebidas das APIs do Google pelos aplicativos funny-spitz-family e EmpreendaComigoH2b está em total conformidade com a Política de Dados de Usuário dos Serviços de API do Google, incluindo todos os requisitos de Uso Limitado (Limited Use).

5. Contato
